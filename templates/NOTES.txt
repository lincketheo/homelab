Pi-hole is starting. First boot downloads blocklists, so give it a few minutes:

  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "pihole.fullname" . }}

Web UI:
{{- if .Values.ingress.enabled }}
  http://{{ .Values.ingress.host }}/admin
{{- else }}
  http://<your-pi>.local:{{ .Values.web.service.port }}/admin
{{- end }}

Admin password:
  kubectl -n {{ .Release.Namespace }} get secret {{ include "pihole.secretName" . }} \
    -o jsonpath='{.data.{{ .Values.admin.passwordKey }}}' | base64 -d; echo

Test DNS:
  dig @<pi-ip> example.com        # should resolve
  dig @<pi-ip> doubleclick.net    # should return 0.0.0.0 (blocked)
